Controles do simulador

Modos

  • Demo — reproduz voo gravado do arquivo Arrow.
  • Fly — voo manual com teclado/controle.
  • Fly + Jam — voo manual com interferência GPS simulada.

Teclado

  • W / S — arfagem (pitch)
  • A / D — rolamento (roll)
  • Q / E ou ← / → — guinada (yaw)
  • Setas ↑ / ↓ — subir / descer
  • Espaço — freio (brake)
  • Shift — boost
  • R — resetar posição
  • J — alternar jamming
  • M — alternar modo
  • C — trocar câmera
  • H — alternar esta ajuda
  • Esc — pausar (somente demo)

Interface

  • Arraste com o mouse para orbitar a câmera.
  • Use os botões de câmera para trocar o ponto de vista.
  • As camadas controlam trajetória, vetores, espaço aéreo e campo.
